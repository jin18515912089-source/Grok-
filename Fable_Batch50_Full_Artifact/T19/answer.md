# RFP 响应：企业客户五项要求

## 1. 合规矩阵
| # | 客户要求 | 状态 | 证据 / 差距 |
|---|---|---|---|
| R1 | 所有生产数据驻留新加坡 | **Comply** | 新加坡数据驻留已上线，可在合同中约定生产数据仅存放于新加坡区域。 |
| R2 | 支持 SAML SSO 并按部门自动配置权限 | **Partial** | SAML SSO：现有能力，Comply。按部门自动配置权限：尚未提供，预计 2027 年上半年进入路线图评审，**尚未承诺**开发或交付日期。 |
| R3 | 提供 SOC 2 Type II 和 ISO 27001 有效证书 | **Partial** | SOC 2 Type II 报告有效至 2027 年 3 月，可提供。ISO 27001：**没有**，且本响应不承诺取得时间。 |

| R5 | 90 天内迁移 500 万条历史记录并完成用户培训 | **Partial** | 培训可与迁移并行，Comply。迁移规模：历史最大项目为 300 万条、用时 75 天；500 万条在 90 天内完成的可行性需先进行两周数据评估后确认。 |

## 2. 差距说明与替代方案
- **R2 部门自动配置权限**：替代方案为 SAML 断言中的部门属性映射至预定义角色（需确认现有能力是否支持属性映射，本响应不作承诺），或由客户管理员通过批量导入维护部门权限。待客户确认：部门层级数量、权限变更频率、是否接受半自动方案。
- **R3 ISO 27001**：替代方案为提供 SOC 2 Type II 报告、控制映射说明，并接受客户的安全问卷与渗透测试结果审阅。待客户确认：ISO 27001 是否为不可豁免条件；若是，需明确本方案无法满足。
- **R4 自动抵扣**：替代方案为在 Enterprise Plus 合同中约定 99.95% 承诺，并写入“月度可用性报告主动提供 + 客户申请后 X 个工作日内完成抵扣”的流程条款（X 待内部确认）。待客户确认：是否接受“主动报告 + 申请制抵扣”。
- **R5 迁移规模**：替代方案为签约后立即启动两周数据评估，评估结论决定：① 90 天全量迁移；② 分阶段迁移（先迁活跃数据，历史归档数据后续迁移）；③ 调整时间表。培训按角色分批，与迁移并行。待客户确认：数据结构复杂度、可接受的分阶段方案、90 天的起算点。

## 3. 实施计划（以两周评估为前置）
| 阶段 | 时间 | 内容 | 交付物 |
|---|---|---|---|
| 0 数据评估 | 第 1–2 周 | 数据量、结构、质量评估；迁移方案与时间表确认 | 评估报告与迁移计划（含是否可 90 天完成的结论） |
| 1 环境与安全 | 第 2–4 周 | 新加坡区域开通、SAML SSO 配置、Enterprise Plus SLA 条款落地 | 生产环境、SSO 联调记录 |
| 2 迁移执行 | 第 4–11 周 | 分批迁移与校验（每批抽样核对） | 迁移批次报告 |
| 3 培训 | 第 5–12 周（并行） | 管理员培训、终端用户分批培训 | 培训记录与材料 |
| 4 验收 | 第 12–13 周 | 数据校验、关键流程验收、上线 | 验收签署 |

注：时间表以评估结论支持 90 天全量迁移为前提；否则将在第 2 周末提交调整方案由客户决定。

## 4. 商业假设
- 报价基于 Enterprise Plus（99.95% SLA 需该版本）；席位与迁移工作量待评估后确定。
- 两周数据评估作为独立工作项，费用与形式待确认。
- 本响应不构成对 ISO 27001、部门自动配置权限或任何未列明能力的承诺。

## 5. 请客户确认
1. ISO 27001 是否为不可豁免条件？
2. R2 是否接受“属性映射 + 批量维护”的半自动方案？
3. R4 是否接受“主动报告 + 申请制抵扣”并写入合同？
4. R5 数据结构与质量情况；是否接受分阶段迁移；90 天起算点。
