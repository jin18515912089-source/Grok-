# 招聘委员会：候选人比较与录用建议

## 1. 加权评分（权重：领域 30%、分析 25%、沟通 20%、执行 15%、领导 10%）
| 候选人 | 领域 | 分析 | 沟通 | 执行 | 领导 | 加权计算 | **加权分** |
|---|---|---|---|---|---|---|---|
| A | 4 | 5 | 3 | 4 | 2 | 1.20+1.25+0.60+0.60+0.20 | **3.85** |
| B | 5 | 3 | 4 | 3 | 4 | 1.50+0.75+0.80+0.45+0.40 | **3.90** |
| C | 3 | 4 | 5 | 5 | 3 | 0.90+1.00+1.00+0.75+0.30 | **3.95** |

排序：C 3.95 > B 3.90 > A 3.85。**三人分差仅 0.10（2.5%），在评分噪声范围内，不足以单凭分数决定。**

## 2. 关键门槛
岗位要求入职后首月独立完成 SQL 分析 → 分析能力 <3 为硬门槛。三人均 ≥3，无人被淘汰；但 **B 恰在门槛（3 分），且面试证据是“SQL 现场题只完成一半”**，属门槛边缘的高风险信号。

## 3. 证据质量与偏差检查
| 候选人 | 支持证据（强） | 弱点证据 | 证据质量评估 |
|---|---|---|---|
| A | 案例分析最强，能找出数据口径错误（直接对应分析维度 5 分） | 跨团队冲突例子较弱（沟通 3、领导 2） | 分析证据具体可验证；协作证据不足 |
| B | 行业经验最深，能带团队（领域 5、领导 4） | SQL 现场题只完成一半（分析 3，门槛边缘） | 领域证据强；核心技能证据弱且与首月要求直接冲突 |
| C | 沟通与执行案例最好（5、5）；领域较浅但能说明学习计划 | 领域经验较浅（3） | 行为证据具体；领域短板可通过学习计划评估 |

**偏差提示**：招聘经理表示“A 的学校和我一样，感觉最靠谱”——学校不是评分维度，属相似性偏差，本建议不予采纳，并已从讨论中剔除。

## 4. 综合判断
- 分数上 C 略领先，但差距不具决定性。
- 从门槛与风险看：B 的核心技能（SQL）证据最弱，与“首月独立完成 SQL 分析”的硬要求直接冲突；A 与 C 的分析证据均达标（A 5 分、C 4 分）。
- 从岗位适配看：若岗位更依赖独立分析与发现数据问题，A 的证据最强；若更依赖跨团队沟通与交付，C 更优。题内岗位要求强调首月独立 SQL 分析，这使 A 与 C 均可胜任，B 存在明确风险。

## 5. 录用建议
**建议：C 为首选，A 为并列强候选；在做出最终决定前完成两项补充验证；B 不建议进入本轮录用。**
理由：C 的加权分最高且分析能力（4）明显高于门槛，沟通与执行证据最具体；领域较浅可通过学习计划与入职支持弥补。A 的分析能力最强，但沟通 3、领导 2 的证据薄弱，需要验证其在跨团队情境下的表现后再决定。B 的领域深度突出，但 SQL 证据与硬门槛冲突，若委员会仍希望考虑 B，必须先补一次完整的 SQL 工作样本测试。

## 6. 复核问题（决定前必须回答）
1. **对 C**：请 C 具体说明领域学习计划的 30/60/90 天目标，并由领域专家评估其可行性；C 是否愿意接受领域导师安排？
2. **对 A**：安排一次以跨团队冲突为主题的结构化行为面试（STAR），由不同于原面试官的两人评分；若沟通/领导证据提升至 ≥3.5，A 与 C 需重新比较。
3. **对 B**（仅在委员会坚持保留时）：补做一次完整的 SQL 工作样本测试（与 A、C 相同题目）；若仍无法独立完成，正式排除。
4. **流程**：确认所有面试官的评分在不知晓招聘经理个人偏好的情况下独立给出；记录并归档偏差提示。

## ASSUMPTIONS_AND_UNKNOWNS

- A 与 C 的补充验证结果未知，最终决定以验证后为准。
- 30/60/90 天学习计划与导师安排为建议。
