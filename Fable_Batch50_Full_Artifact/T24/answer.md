# 内部风险评估备忘录：遗失公司手机事件

**致**：数据保护负责人、信息安全负责人 **自**：隐私运营经理 **性质**：依据公司内部政策的评估，不构成任何司法辖区的法律结论

## 1. 事件事实（已知）
- 一名销售经理在机场遗失公司手机，设备尚未找回。
- 设备控制：启用强密码、全盘加密、自动锁定；未启用生物识别。
- 处置：MDM 在发现遗失后 2 小时完成远程擦除。
- 数据：本地缓存含 48 名企业联系人的姓名、公司邮箱和职位；不含密码、财务或身份证件信息。
- 日志：当前日志未显示擦除前有异常解锁或数据导出；但离线访问日志并不完整。

## 2. 政策适用
| 政策条款 | 本事件对应 |
|---|---|
| 若事件“可能对个人造成风险”，应在知悉后 72 小时内提交监管通知评估 | 本备忘录即为该评估，需在知悉后 72 小时内提交并归档 |
| 若“很可能造成高风险”，应无不当延迟通知受影响个人 | 当前证据不支持“很可能高风险”，见第 3 节 |
| 低风险事件可不通知，但须记录理由、证据和复核日期 | 采用此路径，见第 4 节 |
| 异常解锁、未加密敏感数据或大规模导出迹象将升级为高风险 | 作为触发条件监控，见第 5 节 |

## 3. 当前判断
**结论：当前判断为低风险，暂不通知监管机构或客户。**
理由：
1. 数据敏感度低：仅企业联系人的姓名、公司邮箱、职位，属于业务联系信息；不含密码、财务或身份证件。
2. 技术控制到位：全盘加密 + 强密码 + 自动锁定，且在 2 小时内完成远程擦除，未授权访问的窗口与可能性均受限。
3. 无异常迹象：现有日志未显示异常解锁或导出。
**限定**：以上判断依赖“离线访问日志不完整”这一未消除的不确定性。因此本判断是有条件的，而非最终结论。

## 4. 记录要求（低风险路径）
- 理由：见第 3 节。
- 证据：MDM 擦除记录（时间戳）、设备加密与密码策略配置证明、可用访问日志摘录、缓存数据清单（48 名联系人字段范围）。
- 复核日期：自本评估起 30 天，或任一触发条件出现时立即复核。

## 5. 触发条件（若新证据出现）
| 触发条件 | 升级动作 |
|---|---|
| 发现擦除前存在异常解锁尝试或成功解锁 | 升级为高风险；启动监管通知评估的正式提交与个人通知流程 |
| 发现任何数据导出、同步到未知账户或云端的迹象 | 同上 |
| 发现缓存中存在未识别的敏感数据（如密码、财务、证件） | 同上 |
| 设备被找回且取证显示曾被访问 | 同上 |
| 设备被找回且取证确认未被访问 | 结束事件，记录结论 |

## 6. 证据缺口与待办
1. 离线访问日志为何不完整？能否从 MDM 或操作系统获取补充日志？（负责人：信息安全）
2. 擦除指令的确认回执是否已收到？若设备离线，擦除是否实际执行？（负责人：IT）
3. 48 名联系人所属企业清单及是否包含敏感行业客户（用于个人通知模板准备）。（负责人：销售运营）
4. 自动锁定的时长设置是多少？发现遗失前设备最后一次解锁时间？（负责人：IT）

# 条件性客户通知模板（仅在触发高风险条件后使用）

主题：关于您的业务联系信息的安全事件说明

尊敬的 [联系人姓名]：

我们写信告知您一起涉及您业务联系信息的安全事件。[日期]，我公司一名员工的公司手机在机场遗失。该设备已启用加密与密码保护，并在发现遗失后 2 小时内被远程擦除。

设备本地缓存中包含您的姓名、公司邮箱地址和职位；不包含密码、财务信息或身份证件信息。

我们最初的评估认为风险较低。之后，[简要说明新证据，例如：我们发现擦除前存在一次未经授权的解锁尝试]，因此我们无法排除这些信息被第三方查看的可能性，特此通知您。

目前我们没有证据表明您的信息已被滥用。出于谨慎，建议您对来自不明发件人、冒用我公司或您同事名义的邮件保持警惕。

我们已采取的措施包括：远程擦除设备、[补充措施]，并将持续调查。如有任何进展，我们会及时更新。如您有任何问题，请联系 [联系方式]。

[公司名称] 隐私团队
