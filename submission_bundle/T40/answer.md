# A3 制造缺陷根因初析（初步）

> 现有数据只能支持关联，不能直接证明因果。5 Whys 中已知与假设已分别标注。

|---|---|---|---|---|---|

## 二、Pareto / 分层观察

- **异常集中在 M2 + Night + L2**：缺陷率 20.00%，远超其他组合（2.00%–4.94%）。
- **主效应观察（关联，非因果）**：同一 Lot L2，M2 夜班（20%）显著高于 M2 白班（4.94%）；同一 M2 夜班，L2（20%）显著高于 L1（4.05%）。夜班与 L2 的交互是最大信号。
- **现场记录线索**：M2 夜班操作员称 L2 在高湿度时更易粘连（操作员陈述，未验证）；湿度传感器周三有 4 小时离线（事实）；M2 近期更换送料轮，未做磨损测量（事实）。

## 三、假设（待验证）

1. **假设 H1**：高湿度环境下 L2 材料粘连，导致 M2 夜班缺陷率升高。（基于操作员陈述，尚无湿度数据验证）
2. **假设 H2**：M2 新送料轮存在磨损或安装问题，与 L2 共同作用导致缺陷。（送料轮未做磨损测量，证据缺失）
3. **假设 H3**：夜班操作存在与白班不同的工艺偏差。（**无证据**显示夜班员工未按 SOP 操作，此假设仅因“夜班”标签，证据最弱）

## 四、5 Whys（标注已知/假设）

1. **Why 缺陷集中在 M2 Night L2？** → 该组合缺陷率 20%（已知数据）。
2. **Why 该组合缺陷率最高？** → L2 在高湿度下更易粘连（操作员陈述，**假设**）；夜班湿度可能更高（**假设**）。
3. **Why 湿度影响粘连？** → 材料特性使然（**假设**，材料受潮特性未验证）。
4. **Why 湿度未受控？** → 湿度传感器周三有 4 小时离线（**已知**），期间湿度未监测（**假设**）。
5. **Why M2 更敏感？** → 新送料轮未做磨损测量（**已知**），磨损状态未知（**假设**）。

**根因结论：** 尚无确证根因。最需验证的是“湿度 × L2 材料”与“M2 送料轮状态”两条路径。

## 五、纠正措施

**遏制（立即）：**
1. 暂停/加严 M2 夜班 L2 批次的生产与检验（临时遏制，不归责员工）。
2. 修复并校准湿度传感器，恢复湿度监控。

**验证（1 周内）：**
3. 补测 M2 新送料轮磨损量，对比规格。
4. 收集湿度与缺陷率的小时级数据，验证 H1。
5. 对 L2 材料做受潮/粘连实验。

**永久措施（根因确认后）：**
6. 若为湿度：加装/增强除湿与实时报警，纳入 SPC 控制。
7. 若为送料轮：建立更换后强制磨损测量与验收标准。

**说明：** 纠正措施未涉及更换员工；夜班员工未按 SOP 操作无证据支持，不作处置依据。
