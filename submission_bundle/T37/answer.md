# 客户上线标准作业程序（SOP）

**适用范围：** 所有新客户上线　**负责人：** 客户运营主管

## 一、角色与职责

| 角色 | 职责 |
|---|---|
| 销售 | 合同签署后移交资料，**不得自行承诺上线日期** |
| 客户成功（CS） | 项目主责，执行上线全流程 |
| 实施经理 | 实施、迁移、P1 问题响应 |
| 数据团队 | 数据疑似错误排查 |
| 安全团队 | 安全问卷审批、生产开闸 |
| COO | 紧急例外审批（先开沙箱） |

## 二、标准步骤

| 步骤 | 输入 | 责任人 | 输出 | 控制证据 |
|---|---|---|---|---|
| 1. 项目启动 | 合同、销售移交资料 | CS | 项目立项 | 当日开项记录 |
| 2. 信息确认 | 账单联系人、管理员、数据地区、SSO | CS | 确认清单 | 客户书面确认 |
| 3. 安全问卷 | 客户安全问卷 | 安全团队 | 审批结论 | 安全问卷审批记录 |
| 4. 沙箱实施 | 已确认信息、沙箱环境 | 实施经理 | 沙箱就绪 | 沙箱验收 |
| 5. 管理员培训 | 沙箱 | CS/实施经理 | 管理员可操作 | 培训签到/记录 |
| 6. 迁移前确认 | 迁移数据 | 客户 | 样本数据确认 | 客户签字样本确认 |
| 7. 数据迁移 | 客户数据 | 数据团队/实施经理 | 迁移完成 | 迁移日志 |
| 8. 迁移后抽样 | 迁移结果 | 数据团队 | 抽样结果 | 抽样≥10%且≥100 条记录 |
| 9. 上线确认 | 生产就绪 | 实施经理 + 客户 | 上线日共同确认 | 双方确认记录 |
| 10. 复盘 | 上线后 7/30 天 | CS | 复盘纪要 | 复盘记录 |

## 三、关键控制点

1. **安全问卷为生产开闸前置条件**：无安全问卷不得开生产环境。
2. **销售不得承诺上线日**：上线日期必须由实施经理与客户共同确认。
3. **迁移前必须客户签字**：样本数据确认后方可正式迁移。
4. **迁移后抽样**：抽样 10% 且至少 100 条。
5. **问题升级路径**：P1 问题 → 实施经理；数据疑似错误 → 数据团队。

## 四、例外与紧急处理

- **紧急客户**：可由 COO 批准**先开沙箱**；但安全问卷仍须在 **5 个工作日内补交**。
- 例外必须有批准人记录，事后补录流程与证据。

## 五、完成定义（Definition of Done）

1. 生产环境客户可登录；
2. 关键流程通过验收；
3. 客户签字确认；
4. 支持完成交接。

## 六、常见风险提示

- 客户常晚给用户清单（提前跟进）。
- 销售资料移交不完整（立项时补齐账单联系人、管理员、数据地区、SSO）。
