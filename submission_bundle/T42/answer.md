# 候选人比较与录用建议

**权重：** 领域 30%、分析 25%、沟通 20%、执行 15%、领导 10%（1–5 分）

## 一、加权分计算

| 候选人 | 领域 | 分析 | 沟通 | 执行 | 领导 | 加权分 |
|---|---|---|---|---|---|---|
| A | 4 | 5 | 3 | 4 | 2 | 4×.30+5×.25+3×.20+4×.15+2×.10 = **3.85** |
| B | 5 | 3 | 4 | 3 | 4 | 5×.30+3×.25+4×.20+3×.15+4×.10 = **3.90** |
| C | 3 | 4 | 5 | 5 | 3 | 3×.30+4×.25+5×.20+5×.15+3×.10 = **3.95** |

## 二、关键门槛与证据质量

- **硬门槛**：岗位要求入职首月独立完成 SQL 分析，分析能力低于 3 分为硬门槛。三人分析分分别为 5、3、4，**均不低于 3**，全部通过。
- **证据质量**：
  - A：案例分析最强（能找出数据口径错误）；但跨团队冲突例子较弱，沟通 3、领导 2 偏低。
  - B：行业经验最深（领域 5）、能带团队；但 SQL 现场题只完成一半，分析 3 仅为门槛线。
  - C：沟通与执行案例最好；领域经验较浅（3）但能说明学习计划。
- **无效证据排除**：招聘经理“A 的学校和我一样，感觉最靠谱”不属于评分维度，不予采纳。

## 三、录用建议

**建议录用 C，但需补充验证。** 理由：C 加权分最高（3.95），且在沟通与执行上最强，符合岗位“把复杂结论讲给管理层、带初级分析师”的核心要求；其领域短板（3）有明确学习计划可补偿。

**但分差极小**（C 3.95 / B 3.90 / A 3.85，仅 0.10 差距），建议体现不确定性并做进一步验证：
1. 对 C 补充 SQL 现场题（其领域较浅，需确认独立 SQL 能力是否达首月独立分析要求）。
2. 对 C 的领域学习计划做真实性与可行性核验。
3. 若 C 的 SQL 验证不通过，则回退到 B（领域最强，但需评估其 SQL 只完成一半的风险）。

## 四、复核问题

1. C 的领域学习计划是否有可验证的依据？其 SQL 独立完成能力如何？
2. B 的 SQL 现场题未完成的具体原因（能力缺口还是临场发挥）？
3. A 的领导力（2 分）是否会制约其带初级分析师的职责？
