# 培训需求分析与 30 天学习计划

## 一、培训需求分析（结合错误率与业务影响，不以自评为唯一依据）

| 技能 | 平均自评 | 过去月错误/事件 | 业务影响 | 优先级 |
|---|---|---|---|---|
| 隐私处理 | 4.5（高自评） | 1 次客户名单发错内部群 | **高风险，已撤回** | **P0（最高，自评高但后果最严重）** |
| Excel 公式 | 4.2 | 8 个报告公式错误 | 3 次管理层重发 | P1 |
| 客户沟通 | 2.8 | 2 次升级 | 1 个客户延迟续约 | P2 |
| 数据可视化 | 3.1 | 5 张图标签不清 | 内部返工 | P3 |
| SQL | 2.4 | 3 个慢查询 | 无客户影响 | P4 |

**关键判断：** 隐私处理自评最高（4.5）但后果最严重（高风险），说明“自评高 ≠ 风险低”，必须优先补训；Excel 错误导致 3 次管理层重发，影响直接；客户沟通影响续约，优先级高于 SQL 慢查询（无客户影响）。

## 二、30 天学习计划（每人每周 ≤2 小时）

| 周次 | 主题 | 形式 | 时长 | 成功标准（行为/结果指标） |
|---|---|---|---|---|
| 第 1 周 | 隐私处理 | 60 分钟隐私情景演练 | 1h | 演练中正确识别并拦截高风险分享行为 |
| 第 2 周 | Excel 公式质量 | 90 分钟 Excel 质量工作坊 | 1.5h | 个人报告公式错误数归零（经理抽查） |
| 第 3 周 | 客户沟通 | 每周 30 分钟同伴复核（启动） | 1h | 升级事件数下降，无新增延迟续约投诉 |
| 第 4 周 | 数据可视化 | 同伴复核 + 经理抽查 | 1h | 图表标签不清问题归零（抽查 2 份输出） |

**备注：** SQL 课程（4 小时）因超出每周 2 小时且当前无客户影响，建议 30 天后作为下一阶段安排；经理每周抽查两份输出作为持续校验。

## 三、评估仪表板（指标定义）

| 指标 | 定义 | 目标 |
|---|---|---|
| 报告公式错误数 | 月度报告中被发现并重发的公式错误数 | 3 次 → 0 次 |
| 隐私事件数 | 月度隐私相关高风险事件数 | 0 起 |
| 客户沟通升级数 | 月度客户升级事件数 | 2 次 → 0–1 次 |
| 图表返工数 | 因标签不清导致的返工图数 | 5 张 → 0 张 |
| 抽查通过率 | 经理抽查输出合格的比例 | ≥ 90% |

**原则：** 不以“完成课程”作为唯一成功标准，而以错误率下降与业务影响消除作为培训成功指标。
