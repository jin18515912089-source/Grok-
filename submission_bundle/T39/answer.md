# 供应商加权评分与采购建议

## 一、硬门槛筛查

**Security 低于 80 为不可豁免淘汰。**

| 供应商 | Security | 是否通过 |
|---|---|---|
| X | 95 | ✅ |
| Y | 70 | ❌ 淘汰（Security < 80） |
| Z | 90 | ✅ |

**Y 因 Security 70 < 80 被直接淘汰，不论总分高低。**

## 二、Cost Score 计算

公式：Cost Score = 最低合格报价 / 该供应商报价 × 100
合格供应商最低报价 = X（1.00 百万美元）。

| 供应商 | 报价 | Cost Score |
|---|---|---|
| X | 1.00 | 1.00/1.00×100 = **100.00** |
| Z | 1.20 | 1.00/1.20×100 = **83.33** |

## 三、加权总分

权重：Cost 30%、Quality 25%、Delivery 20%、Security 15%、Sustainability 10%。

**X：**
= 100×0.30 + 85×0.25 + 70×0.20 + 95×0.15 + 60×0.10
= 30 + 21.25 + 14 + 14.25 + 6 = **85.50**

**Z：**
= 83.33×0.30 + 95×0.25 + 80×0.20 + 90×0.15 + 90×0.10
= 25.00 + 23.75 + 16.00 + 13.50 + 9.00 = **87.25**

## 四、评分结果

| 排名 | 供应商 | 总分 | 状态 |
|---|---|---|---|
| 1 | Z | 87.25 | 推荐 |
| 2 | X | 85.50 | 备选 |
| — | Y | — | 淘汰（硬门槛） |

## 五、采购建议

**推荐供应商 Z**：总分最高（87.25），且满足 Security 硬门槛；报价 1.20 百万美元在 1.25 百万美元项目总预算之内。

## 六、谈判要点

1. **价格**：Z 报价最高（1.20M），可谈判降价以逼近 X 的 1.00M，进一步释放预算余量。
2. **Delivery（80）**：Z 的交付分低于满分，谈判时要求明确交付时间表与里程碑承诺。
3. **锁定 Security 门槛**：任何谈判不得降低 Security 门槛（<80 即淘汰），Z 的 Security 90 应写入合同保证。
4. **Sustainability 优势**：Z 的 90 为三家中最高，可作为合同中的可持续条款锚点。

**说明：** 不因总分最高而绕过硬门槛；Y 的 Security 70 已触发不可豁免淘汰。
