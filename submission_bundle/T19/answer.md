# 企业客户 RFP 响应（五项要求）

**响应原则：** 如实响应，不把路线图能力写成现有能力；对 Partial/No 给出替代方案与待确认问题。

## 一、合规矩阵

| # | 客户要求 | 状态 | 证据 / 差距 |
|---|---|---|---|
| R1 | 所有生产数据驻留新加坡 | **Comply** | 新加坡数据驻留已上线 |
| R2 | SAML SSO + 按部门自动配置权限 | **Partial** | SAML SSO 已支持；按部门自动配置权限预计 2027 年上半年进入路线图评审，**尚未承诺** |
| R3 | SOC 2 Type II + ISO 27001 有效证书 | **Partial** | SOC 2 Type II 有效至 2027 年 3 月；**无 ISO 27001** |
| R4 | 99.95% 月度可用性 SLA + 未达标自动抵扣 | **Partial** | 标准 SLA 99.9%；Enterprise Plus 可合同约定 99.95%；服务抵扣需客户提交申请，**不自动** |
| R5 | 90 天内迁移 500 万条历史记录 + 完成用户培训 | **No** | 历史最大迁移项目为 300 万条、用时 75 天；500 万条/90 天可行性需先做两周数据评估；培训可在迁移期并行 |

## 二、差距与替代方案

1. **R2（权限自动配置）**：当前可用 SSO + 手动/半自动配置作为过渡；自动配置上线前建议采用“角色模板 + 定期对账”的过渡方案。**待确认：** 客户可接受的过渡期时长与权限粒度。
2. **R3（ISO 27001）**：我方无 ISO 27001，可提供 SOC 2 Type II（有效）及安全白皮书/渗透测试等替代性安全证据。**待确认：** 客户是否可接受以 SOC 2 Type II 替代 ISO 27001。
3. **R4（SLA 自动抵扣）**：可提供 Enterprise Plus 的 99.95% 合同 SLA；抵扣为“申请制”而非“自动”。**待确认：** 客户是否接受申请制抵扣，或是否可加价支持自动抵扣机制。
4. **R5（500 万条迁移）**：建议先做两周数据评估（范围、数据质量、映射复杂度），再给出 90 天可行性与分阶段计划。**待确认：** 客户是否接受“评估后再承诺迁移时间表”。

## 三、实施计划（草案）

1. **第 0–2 周**：两周数据评估（500 万条可行性）；启动新加坡数据驻留配置确认；对齐 SSO 权限模型。
2. **第 2–6 周**：迁移方案设计 + 沙箱迁移验证；并行开展管理员与用户培训。
3. **第 6–12 周**：分阶段正式迁移（按评估结果分批次）；培训持续并行。
4. **第 12 周**：验收、SLA 切换（如选 Enterprise Plus）。

> 迁移时间线为条件性计划，正式承诺须以两周数据评估结论为准。

## 四、商业假设（Assumptions）

1. 迁移 500 万条指历史业务记录条数，非用户数（待与客户确认口径）。
2. R4 的 99.95% SLA 按 Enterprise Plus 合同条款适用。
3. 数据评估所需客户配合（数据样例、字典、接口）可按时到位。
4. 无 ISO 27001 的缺口可通过合同、SOC 2 Type II 与安全评估补充，待客户确认。

**说明：** 未虚构认证、功能或承诺题内未授权的开发日期。
