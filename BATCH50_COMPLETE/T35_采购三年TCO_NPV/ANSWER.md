### FILE: Vendor_TCO_NPV.xlsx
单位：千美元。折现率 8%。实施+培训在 t=0；年度费用在每年末。Vendor B 迁移费在第 1 年末。Residual 在第 3 年末作现金流入抵减成本。功能/安全硬门槛均已满足。

**现金流（成本为正，残值为负流入）**

| | A | B | C | 时点 |
|---|---:|---:|---:|---|
| 实施 t0 | 220 | 150 | 300 | t=0 |
| 培训 t0 | 60 | 90 | 40 | t=0 |
| t0 小计 | 280 | 240 | 340 | |
| Y1 许可 | 380 | 300 | 450 | 年末 |
| Y1 支持 | 40 | 65 | 25 | |
| Y1 停机 | 25 | 80 | 10 | |
| Y1 迁移 | 0 | 50 | 0 | 年末 |
| Y1 合计 | 445 | 495 | 485 | |

| Y3 残值 | 0 | 0 | −120 | 年末流入 |
| Y3 净 | 445 | 476 | 365 | |

NPV = t0 + Y1/1.08 + Y2/1.08^2 + Y3/1.08^3  
Excel：`=t0+Y1/1.08+Y2/1.08^2+Y3/1.08^3`

| | 名义三年总成本 | NPV(8%) |
|---|---:|---:|
| Vendor A | 1,615 | **1,426.81** |
| Vendor B | 1,671 | 1,470.57 |
| Vendor C | 1,675 | 1,494.63 |

名义与 NPV 排序均为 A < B < C。A 最低 NPV。

**敏感性（说明，非穷尽）**  
- 若 B 停机成本从 80 降到与 A 相同 25：B 的 Y1 变为 440、Y2 405、Y3 421，NPV 将明显下降（约降 80×(1/1.08+1/1.08^2+1/1.08^3)≈206），可能低于 A——故 B 的排序高度依赖最不确定的停机假设。  
- C 残值 120 折现 ≈95，若残值为 0，C 的 NPV 升至约 1,590，更差。  
- 折现率 ±2 个百分点不改变 A 最低的方向（A 的后期成本形态与 B/C 相近且 t0 并非最高中的最差）。

### 采购建议（≤500字）
财务口径选 **Vendor A**（NPV 1,426.8 千美元最低）。不可只看名义许可：B 许可看起来最低（300 起），但停机 80+迁移 50+支持 65 把 Y1 推到 495，NPV 反高于 A。C 许可和支持最好看、残值 120 有退出回收，但 t0 实施 300 最重，NPV 最高。

非价格：运营指出 A 仅两个同规模客户，C 有六个——实施风险 A 高于 C，与 NPV 排序相反。B 许可逐年上涨（300/315/331）且停机假设最不确定，作主选不稳。

建议：以 A 为首选进入谈判，合同写入停机 SLA 与实施验收；并行对 C 做实施风险尽调（六个同规模客户可参考）。若尽调显示 A 交付失败成本接近停机差额，再切换 C。不选 B，除非停机成本能被合同 SLA 实质压到接近 25。
